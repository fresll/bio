# Интерактивные семинары по биологии

Кафедра биологии и генетики · Медицинский университет Петровского · курс «Биология», 1–2 семестры.

Страницы для студентов (GitHub Pages). Главная `index.html` — три раздела: `section-1.html` (I. Биология клетки, семинары 1–6), `section-2.html` (II. Матричные процессы, семинары 7–11), `section-3.html` (III. Происхождение клетки и эволюция: семинар 12; семинары по эволюции 2 семестра — в разработке); общие стили разделов — `sections.css`. Главная и страницы разделов оформлены по образцу «Оглавление» (24.11.2026): шапка MAZUNIN / EDU с переключателем курсов «Биология / Молекулярная биология», на главной четыре карточки разделов 2 × 2 с миниатюрами, на странице раздела — цель, карточки семинаров в две колонки («Объяснения», «Практикум», свёрнутые «Темы семинара») и ссылки на материалы раздела; стили — `catalog.css` (общий файл с сайтом «Молекулярная биология», действует только на страницах с `<body class="cat">`). У каждого семинара практикум `seminar-N.html` и «Объяснения» `seminar-N-route.html`. Страницы закрыты от индексации (`noindex, nofollow`).

**Версии на сайте не показываются (с 23 ноября 2026 г., решение автора).** Строки «Версия N · Выпуск …» в подвалах, плашки «Семинар N · vX» в шапке «Объяснений» и ключ `version` в практикумах убраны со всех 44 страниц; студент номера версии не видит. Номера версий и выпусков ниже — внутренние: для кафедры и журнала правок. Пересборка из каркаса не возвращает версию: последний шаг `build_all.sh` — `без_версий.py`; в реестре откатов — запрет «Версия N · Выпуск».
