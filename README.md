# Интерактивные семинары по биологии

Кафедра биологии и генетики · Медицинский университет Петровского · курс «Биология», 1–2 семестры.

Страницы для студентов (GitHub Pages). Главная `index.html` — три раздела: `section-1.html` (I. Биология клетки, семинары 1–6), `section-2.html` (II. Матричные процессы, семинары 7–11), `section-3.html` (III. Происхождение клетки и эволюция: семинар 12; семинары по эволюции 2 семестра — в разработке); общие стили разделов — `sections.css`. У каждого семинара практикум `seminar-N.html` и «Объяснения» `seminar-N-route.html`. Страницы закрыты от индексации (`noindex, nofollow`).
